# Ava Silver's Personal Website

This is the source code for my personal website. It is built using [Astro](https://astro.build) and managed with [Bun](https://bun.sh), and serves as a source for basic information about me and how to contact me.

## Development

Install dependencies with `bun install`, then run `prek install` to set up pre-commit hooks (lint + format checks).
